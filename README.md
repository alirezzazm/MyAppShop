# MyAppShop

وب‌اپ معرفی نرم‌افزارها و اپلیکیشن‌ها؛ چندزبانه، ریسپانسیو و بدون هیچ وابستگی build.
فقط HTML، CSS و JavaScript خالص است، پس روی هر هاست استاتیکی (GitHub Pages، Netlify، Vercel، یا هاست معمولی) بالا می‌آید.

A multilingual showcase site for software products, with an app-request and consultation form.
Plain HTML, CSS and JavaScript — no build step, no dependencies.

---

## امکانات

- **۸ زبان:** انگلیسی، عربی، فارسی، فرانسوی، ایتالیایی، اسپانیایی، آلمانی، ترکی
- **پشتیبانی کامل RTL** برای عربی و فارسی (چیدمان با logical properties، بدون CSS جداگانه)
- تشخیص خودکار زبان مرورگر، ذخیره انتخاب کاربر، و لینک مستقیم با `?lang=fa`
- **پوسته تیره و روشن** با ذخیره انتخاب کاربر
- گالری محصولات با فیلتر (موبایل / وب / دسکتاپ / هوش مصنوعی)
- **صفحه کامل جزئیات برای هر محصول**: معرفی، نمای داخل برنامه، نقاط قوت، جدول مشخصات، فراخوان سفارش و محصولات مرتبط — برای هر محصول در هر زبان یک صفحه استاتیک جدا
- **سئوی چندزبانه:** یک صفحه استاتیک جداگانه برای هر زبان (`fa.html`، `ar.html`، …) که موتورهای جستجو و ربات‌های پیش‌نمایش لینک بدون اجرای جاوااسکریپت می‌خوانند، به‌همراه hreflang، canonical، داده ساختاریافته JSON-LD، تصویر Open Graph، sitemap و robots
- صفحه ۴۰۴ اختصاصی
- **فرم ثبت درخواست اپ و مشاوره** با اعتبارسنجی چندزبانه، تله ربات (honeypot) و پیام موفقیت
- بخش‌های مزایا، روند کار، نظرات مشتریان و پرسش‌های متداول
- انیمیشن ورود عناصر، شمارنده آمار، و احترام به `prefers-reduced-motion`
- دسترسی‌پذیری: skip link، فوکوس مشخص، برچسب‌های ARIA، ناوبری با کیبورد

## اجرای محلی

```bash
npx http-server -p 8080
# سپس http://localhost:8080
```

هر سرور استاتیک دیگری هم کار می‌کند. باز کردن مستقیم `index.html` هم کار می‌کند چون هیچ فایلی با `fetch` بارگذاری نمی‌شود.

## ساختار

```
index.html                  ساختار صفحه (همه متن‌ها با data-i18n نشانه‌گذاری شده‌اند)
404.html                    صفحه خطای ۴۰۴
robots.txt / sitemap.xml    فایل‌های سئو (دامنه را باید جایگزین کنید)
assets/css/styles.css       استایل، توکن‌های رنگ، پوسته روشن/تیره، ریسپانسیو
assets/img/og.png           تصویر اشتراک‌گذاری در شبکه‌های اجتماعی
product.html                قالب صفحه جزئیات محصول
assets/js/i18n-data.js      دیکشنری همه زبان‌ها + فهرست زبان‌ها
assets/js/products.js       داده محصولات و نام مشتریان
assets/js/product-view.js   سازنده مشترک صفحه جزئیات (مرورگر + prerender)
assets/js/product-page.js   کنترل صفحه جزئیات
assets/js/app.js            منطق: زبان، پوسته، فیلتر، دیالوگ محصول، فرم، سئو
tools/prerender.js          ساخت صفحه استاتیک هر زبان + sitemap + robots
.github/workflows/pages.yml انتشار خودکار روی GitHub Pages
```

فایل‌های `fa.html`، `ar.html` و …، صفحات محصول مثل `taskflow.fa.html`، و همچنین `sitemap.xml` و `robots.txt` **تولیدی** هستند و در مخزن نگه‌داری نمی‌شوند؛ هنگام انتشار ساخته می‌شوند.

## شخصی‌سازی

### افزودن یا ویرایش محصول

۱. یک آیتم به `window.PRODUCTS` در `assets/js/products.js` اضافه کنید:

```js
{
  id: 'myapp',
  cats: ['mobile', 'ai'],          // برای فیلترها
  accent: '#7c6cf6',               // رنگ کارت
  platforms: ['iOS', 'Android'],
  rating: '4.8',
  users: '12K',
  link: '#contact',                // یا لینک صفحه محصول / استور
  icon: '<svg …></svg>'
}
```

۲. این کلیدها را به **همه** زبان‌ها در `i18n-data.js` اضافه کنید:

| کلید | کجا دیده می‌شود |
| --- | --- |
| `p.myapp.name` | نام محصول |
| `p.myapp.tag` | دسته‌بندی |
| `p.myapp.desc` | توضیح کوتاه، روی کارت و زیر عنوان صفحه جزئیات |
| `p.myapp.long` | بخش «معرفی کلی» در صفحه جزئیات |
| `pd.myapp.h1` تا `h3` | سه نقطه قوت در صفحه جزئیات |

با اجرای دوباره `tools/prerender.js` صفحه جزئیات آن محصول برای هر هشت زبان ساخته می‌شود.
اگر می‌خواهید کارت محصول به‌جای صفحه جزئیات به لینک بیرونی (مثلاً صفحه اپ‌استور) برود، فیلد `link` را در `products.js` پر کنید.

### افزودن زبان جدید

۱. یک آیتم به `window.LANGS` اضافه کنید (`dir: 'rtl'` برای زبان‌های راست‌به‌چپ).
۲. یک دیکشنری با همان کلیدهای `window.I18N.en` بسازید.
کلیدهای جانیفتاده به‌صورت خودکار از انگلیسی پر می‌شوند، پس ترجمه ناقص هم صفحه را نمی‌شکند.

### اتصال فرم به سرویس واقعی

به‌صورت پیش‌فرض، فرم ایمیل کاربر را با محتوای درخواست باز می‌کند (`mailto`).
برای دریافت مستقیم درخواست‌ها، در ابتدای `assets/js/app.js` آدرس سرویس فرم را وارد کنید:

```js
var CONFIG = {
  formEndpoint: 'https://formspree.io/f/XXXXXXX',   // یا Getform، Basin، یا API خودتان
  contactEmail: 'hello@myappshop.com',
  defaultLang: 'en'
};
```

سرویس یک `POST` با بدنه JSON دریافت می‌کند شامل: نوع درخواست، نام، ایمیل، تلفن، شرکت، پلتفرم‌ها، بودجه، زمان‌بندی، متن پروژه و زبان کاربر.
یک نسخه از هر درخواست در `localStorage` هم نگه داشته می‌شود تا در صورت قطعی شبکه چیزی از دست نرود.

### اطلاعات تماس و برند

ایمیل، شماره تماس و لینک شبکه‌های اجتماعی در `index.html` (بخش تماس و فوتر) قرار دارند.
رنگ‌های برند در بالای `styles.css` تعریف شده‌اند: `--brand`، `--brand-2`، `--brand-3`.

## صفحه مجزا برای هر زبان (مهم برای دیده‌شدن)

ربات‌های گوگل و پیش‌نمایش لینک در واتساپ، تلگرام، لینکدین و ایکس جاوااسکریپت اجرا نمی‌کنند.
یعنی اگر فقط `index.html` منتشر شود، لینک فارسی شما همه‌جا با عنوان و توضیح انگلیسی نمایش داده می‌شود.

برای همین یک اسکریپت کوچک، برای هر زبان یک صفحه کامل و آماده می‌سازد:

```bash
node tools/prerender.js https://your-domain.com
```

خروجی:

- یک صفحه اصلی برای هر زبان: `en.html`، `ar.html`، `fa.html`، `fr.html`، `it.html`، `es.html`، `de.html`، `tr.html`
- یک صفحه جزئیات برای هر محصول در هر زبان: `taskflow.fa.html`، `lingua.ar.html` و … (۶ محصول × ۸ زبان = ۴۸ صفحه)
- `sitemap.xml` و `robots.txt` با دامنه واقعی شما

صفحه جزئیات محصول با همان کدی ساخته می‌شود که مرورگر استفاده می‌کند (`assets/js/product-view.js`)، پس خروجی استاتیک و نسخه‌ای که جاوااسکریپت می‌سازد دقیقاً یکی هستند.

هر صفحه `lang` و `dir` درست، عنوان و توضیح ترجمه‌شده، تگ‌های Open Graph و داده ساختاریافته مخصوص همان زبان را دارد.
جاوااسکریپت هم می‌داند روی کدام صفحه است و زبان را عوض نمی‌کند؛ تغییر زبان از منو، کاربر را به صفحه همان زبان می‌برد.
`index.html` مثل قبل کار می‌کند و زبان را در جا عوض می‌کند.

## انتشار روی GitHub Pages

در تنظیمات مخزن، بخش **Settings → Pages**، گزینه Source را روی **GitHub Actions** بگذارید.
با هر push روی شاخه `main` سایت به‌صورت خودکار منتشر می‌شود.
workflow خودش `tools/prerender.js` را با آدرس واقعی سایت اجرا می‌کند، پس نیازی به تنظیم دستی دامنه نیست.

برای هاست‌های دیگر (Netlify، Vercel، هاست معمولی) کافی است قبل از آپلود یک بار اسکریپت را با دامنه خودتان اجرا کنید.
